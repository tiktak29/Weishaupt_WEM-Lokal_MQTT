# Weishaupt WEM-Lokal MQTT

Local gateway for Weishaupt heat pumps with automatic WebIF and device detection, exposing local data to Home Assistant via MQTT Discovery – completely local and cloud-free.

Version **1.1.2** adds support for heat pumps whose WebIF displays a single heating circuit as `Heizkreis` without a number. Existing numbered heating circuits remain supported. No configuration changes are required when updating from v1.1.1.
